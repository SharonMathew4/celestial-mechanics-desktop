# Feature Matrix

This matrix compares the features implemented in Simulation Mode with those planned for Observation Mode.

| Feature Area | Simulation Mode (Interactive Sandbox) | Observation Mode (Scientific Explorer) |
|---|---|---|
| **Target User** | Game developers, educators, physics enthusiasts | Amateur astronomers, students, space researchers |
| **Physics Solver** | Active integrators (Verlet, Euler, RK4) | Predetermined Keplerian orbits / Ephemeris lookup |
| **Data Source** | User-created custom files (`.cesim`) | Real-world astronomical databases (NASA JPL, Gaia) |
| **Editable Parameters**| Active addition/deletion/editing of bodies | Static historical data; timeline scrubber control |
| **Telemetry & Graphs** | Dynamic velocity, energy, and path graphs | Distance, magnitude, classification, parallax charts |
| **Rendering Overlays** | Collision bounds, vectors, trail buffers | Constellation boundaries, grid lines, celestial coordinates |
| **AI Assistants** | Scenario advisor and orbital stability analyst | AI Tour guide, information summarizer, entity lookups |
| **Camera Modes** | Perspective target orbiting, free flying | Earth-based gaze tracker, telescope focal views |
