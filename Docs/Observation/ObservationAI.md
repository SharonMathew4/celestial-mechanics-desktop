# Observation AI Assistant

This document details the planned integration of LLM assistants into Observation Mode.

## 1. AI Tour Guide

- Embed a local LLM or API integration to act as a cosmic tour guide.
- Users can ask questions like "Tell me about Betelgeuse's spectral characteristics" or "Generate an educational tour of the Solar System."

## 2. Dynamic Target Framing
- The AI assistant can execute camera movement actions to frame targets in response to user conversations.
