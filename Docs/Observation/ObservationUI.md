# Observation UI Layout

This document defines the layout specifications and requirements for the Observation Mode user interface.

## 1. Interface Panels

- **Stellar Search Sidebar**: Allows searching catalogs by star name, ID, or sky coordinates.
- **Time Scrub Controller**: Controls historical timeline navigation.
- **Catalog Filter Sidebar**: Toggle visibility of constellations, grids, star classes, and nebulae.
- **Spectroscopic Detail Panel**: Displays astrophysical details (spectral class, distance, magnitude, absolute parallax) of the selected object.

## 2. Interactive Overlay
- Interactive annotations for bodies, labels that scale with camera distance, and orbital indicators.
