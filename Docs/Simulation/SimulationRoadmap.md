# Simulation Mode Roadmap

This document outlines the planned work items and features specifically for the simulation sandbox module.

## Short-term Tasks
- [ ] Connect native C++/CUDA solvers for massive simulations.
- [ ] Implement collision response physics (coalescence vs. fragmentation).
- [ ] Add orbital prediction visualizers showing expected paths under Keplerian approximation.

## Long-term Tasks
- [ ] Add planetary ring system rendering.
- [ ] Support custom atmospheric rendering shaders on planet surfaces.
- [ ] Integrate an automated orbital stability advisor utilizing neural approximations.
